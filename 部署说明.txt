词页单词本 · Windows 64 位便携版

在其他电脑上使用

1. 把 ZIP 文件复制到目标 Windows 64 位电脑。
2. 右键 ZIP，选择“全部提取”，将整个文件夹解压到你能写入的位置。
   不要直接在压缩包内运行，也不要只复制某个启动文件。
3. 双击“打开单词本.vbs”，等待浏览器打开单词本。
   如果这台电脑禁用了 VBS，可双击“开始使用.cmd”。
4. 输入单词并按 Enter，即可自动查询剑桥词典。
   主词下的“＋ 添加相关词”用于记录变形和派生词，也能自动查询音标和释义。
   底部日期可打开日历翻页，上方可检索已收录单词，每个单词可设 0–10 个重点标记。
   顶部“同义替换”可以一行记录多个近义词；“语料积累”可添加条目自由输入。

程序已经包含运行环境和依赖，无需另外安装 Node.js 或运行安装命令。
这是 Windows 64 位版本，不适用于 macOS、Linux 或 32 位 Windows。

单词与备份

本部署包初始单词本为空。正式单词会保存在解压后文件夹的 data 目录中。
迁移原电脑上的单词：先在原单词本点击“导出备份”，再在新电脑点击
“导入备份”，选择导出的 JSON 文件。CSV 表格用于阅读，不能代替完整备份。
JSON 备份包含主词、相关词的全部词性、重点标记、同义词组、语料积累和复习记录。

今后可以备份整个程序文件夹，尤其要保留 data 目录。
两台电脑各自保存单词，不会自动同步；使用 JSON 备份转移内容。
浏览器中的遮挡列选择属于本机设置，新电脑上可以重新选择。

升级以前的 Windows 版

先在旧版导出 JSON 备份，再解压本新版到新文件夹。重启电脑后打开新版，
导入旧备份。请保留旧文件夹及其 data 目录，直到确认新版本内容完整。
新版支持旧版 JSON 备份；包含重点标记、相关词词性和语料积累的新版备份需用新版打开。

打开与关闭

浏览器地址：http://127.0.0.1:17865/
如果浏览器没有自动打开，可在启动后手动访问上述地址。
重启电脑后，再次双击启动文件即可使用。
关闭浏览器后，本地服务可能继续运行；重启电脑会结束它。

查词需要联网；已经保存的单词可以离线查看和编辑。
复习提醒显示在单词本网页内，关闭网页后不会发送桌面通知。
如果启动失败，可以查看 data/server-error.log。
如果目标电脑有组织管理限制，应使用其允许的软件运行方式。

文件夹中的“使用说明.md”包含录词、编辑、复习和自我检查的完整说明。
