# 词页 · 英语单词本（Windows 本地版）

一个在本机浏览器中使用的英语学习工具。记录新词、整理相关词和同义替换、积累语料，并通过间隔复习和遮挡答案进行自我检查。

## 主要功能

- **剑桥查词**：首次输入主词或相关词后，查询 Cambridge Dictionary 的英式音标、词性与中文释义；不同词性分行显示，可打开词典原页。
- **自由编辑**：日期、序号、单词、音标、词性、释义和链接都可修改，支持手动添加词性。
- **二级相关词**：在主词下整理词形变化、派生词和关系说明，随主词一起复习。
- **日历与检索**：同一天收录的单词集中在同一页；使用日历翻页，或检索全部已收录主词与相关词。
- **间隔复习**：默认在收录当日及之后第 1、2、6、14、30 天安排复习，可修改间隔，并补记逾期任务。
- **遮挡自测**：看词想义、看义想词、自由隐藏列和逐词揭晓。
- **重点标记**：每个主词与相关词均可独立设置 0–10 个重点标记。
- **同义替换**：一行整理多个近义词、共同含义和辨析笔记，全部手动填写。
- **语料积累**：自由记录多行例句、表达、摘录和笔记。
- **保存与备份**：本地自动保存、撤销删除、JSON 完整备份与恢复、CSV 表格导出。

## 从源码运行

安装 Node.js 22 或更高版本，在本目录打开终端：

```sh
npm ci
npm start
```

浏览器访问 <http://127.0.0.1:17865/>。停止服务时，在终端按 `Ctrl+C`。

项目同时保留 `pnpm-lock.yaml`，也可使用 pnpm：

```sh
pnpm install --frozen-lockfile
pnpm start
```

源码仓库不包含 Node.js 运行环境和已安装依赖。`打开单词本.vbs`、`开始使用.cmd` 与 `launch.ps1` 是便携部署包的入口，需要配套的 `runtime/node.exe` 和 `node_modules`；直接下载源码请使用上面的命令启动。

如已获得包含运行环境的 Windows 64 位 ZIP，完整解压后双击 `开始使用.cmd` 即可使用。参见 [部署说明](部署说明.txt) 和 [完整使用说明](使用说明.md)。

## 数据与迁移

- 首次使用为空单词本，内容保存在本机 `data/wordbook.json`。
- `data/wordbook.previous.json` 保存上一版，`data/backups/` 保存每日修改前快照。
- 三个页面的“导出备份”均包含全部单词、相关词、同义词组、语料、重点标记、设置和复习记录。
- 换电脑时，先在原电脑导出 JSON，再在新电脑导入。导入会替换当前内容；CSV 用于查看整理，不能代替完整备份。
- `.gitignore` 排除了个人数据、备份、日志、依赖、运行环境和部署包；这些内容不会随源码上传。
- 没有账号或自动跨设备同步。网页关闭后不会发送桌面复习通知。

## 联网查询

查词时会把输入的英文单词发送到 Cambridge Dictionary；已保存的内容可离线查看和编辑。同义替换与语料积累无需联网查询。

自动查询解析剑桥公开网页，第三方页面变化或连接限制可能导致失败；此时可重试、打开词典原页或手动填写。缺少 UK 音标时留空，不用美式音标代替。该项目与 Cambridge Dictionary 无隶属关系。

## 开发与测试

```sh
npm test
```

测试使用临时目录，不读取或覆盖个人单词数据。HTTP 测试使用本机端口 `17867`。

可通过环境变量 `WORDBOOK_PORT` 修改服务端口，通过 `WORDBOOK_DATA_DIR` 指定数据目录。服务仅监听 `127.0.0.1`。

## 文件结构

```text
public/          页面、样式、词条模型与复习界面
tests/           数据、查词和 HTTP 测试
server.mjs       本地服务与保存接口
dictionary.mjs   剑桥词典查询与解析
launch.ps1       Windows 便携包启动入口
```

本仓库为 Windows 本地版，不包含 iOS 工程。
